Pharmacy Management System Using C++

1. Project Overview

The Pharmacy Management System is a C++ application developed using Object-Oriented Programming (OOP). It is designed to manage pharmacy operations and organize medicine information.

2. Project Objectives

- Organize medicine information.
- Manage medicine quantities.
- Search for medicines easily.
- Calculate medicine sales.
- Save and retrieve data using files.

3. Main Features

1. Add new medicines.
2. Display all available medicines.
3. Search for medicines by ID.
4. Sell medicines and calculate the total price.
5. Save medicine data in text files.
6. Load saved data when the program starts.

4. Medicine Information

Each medicine contains:

- Medicine ID
- Medicine Name
- Price
- Quantity
- Medicine Type

5. Object-Oriented Programming Concepts

- Classes and Objects
- Encapsulation
- Constructors
- Inheritance
- Polymorphism

6. File Handling

The system uses text files to store medicine information and retrieve it when the application starts.

7. Programming Language

C++
